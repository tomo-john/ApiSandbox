# $request->query()と$request->input()

どちらもHTTPリクエストから値を取得するメソッド。

取得対象となるデータの範囲が異なる。

## それぞの違い

| メソッド | 取得するデータ                           | 主な用途                       |
| -------- | ---------------------------------------- | ------------------------------ |
| input()  | リクエストの入力データ(クエリ文字列含む) | POST・PUTなどの入力値の取得    |
| query()  | URLのクエリ文字列のみ                    | 検索条件・ページ番号などの取得 |

`input()`はクエリ文字列とリクエストボディの両方を対象にするのに対し、`query()`はクエリ文字列だけを対象とする。

## HTTPリクエストで比較

```http
POST /api/dogs?status=active HTTP/1.1
Host: example.com
Content-Type: application/json

{
    "name": "じょん",
    "age": 2
}
```

- URLのクエリ文字列: `status=active`
- リクエストボディ: `name=じょん`, `age=2`

- `$request->input('name')` : "じょん"
- `$request->input('age')` : "2"
- `$request->input('status')` : "active"
- `$request->query('status')` : "active"
- `$request->query('name')` : null

`query()`はクエリ文字列からしか値を取得できない。

## 同じキーがクエリ文字列とリクエストボディの両方に存在するとき

`input()`はリクエストボディの値を優先する。

=> 同じキーがあれば、ボディ側の値が取得される

`query()`はクエリ文字列だけを見るので、ボディ側の値は影響しない。

- 🐶 input()：リクエストの入力値を幅広く取得する
- 🐶 query()：URLの ? 以降のクエリ文字列だけを取得する
- 🐶 input() は同じキーがある場合、リクエストボディの値を優先する

## 第二引数

`query()`の第二引数にはデフォルト値を設定することができる。

```php
<?php
$per_page = $request->query('per_page', 10);
```

HTTPリクエストに`per_page`のクエリ文字列がなければ、`10`、あれば取得した値を採用する。

第二引数のデフォルト値は、基本的にそのキーが存在しない場合に使用される。

空文字や`0`が渡された場合には、その値が取得されるので注意。
