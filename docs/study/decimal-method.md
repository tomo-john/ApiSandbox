# 小数を扱う主な型

| メソッド    | DB型    | 特徴                                         |
| ----------- | ------- | -------------------------------------------- |
| `decimal()` | DECIMAL | 桁数と小数桁数を指定できる。金額などに適する |
| `float()`   | FLOAT   | 浮動小数点数。近似値を扱う                   |
| `double()`  | DOUBLE  | FLOATより高い精度の浮動小数点数              |

## decimal()

```php
<?php
$table->decimal('weight', total: 4, places: 1);
```

- `total: 4`: 整数部分と小数部分を合わせた最大桁数
- `places: 1`: 小数点以下の桁数

=> `123.4`みたいなの。(`999.9`まで表現できる)

## FLOATとDOUBLE

こちらは固定の小数桁数を指定する。

`DECIMAL`とは異なり、浮動小数点数として数値を近似値的に保存する型。

=> コンピュータ内部では、0.1 + 0.2が厳密には0.3にならない場合がある

- FLOAT: 一般に単精度。メモリ使用量が少なめで、精度は低め。
- DOUBLE: 一般に倍精度。より多くの桁を扱えるが、メモリ使用量も増える。

## どれを使う？

| 用途                    | 型の候補       |
| ----------------------- | -------------- |
| 商品価格・金額          | DECIMAL        |
| 犬の体重・小数第1位まで | DECIMAL        |
| センサーの測定値        | FLOAT / DOUBLE |
| 科学技術計算            | DOUBLE         |
